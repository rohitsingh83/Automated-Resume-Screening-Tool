# GitHub Setup & 6-Day Commit Plan

- **Recommended Repo Name:** `Automated-Resume-Screening-Tool`
- **Description:** Python & NLP ATS resume screening pipeline using TF-IDF cosine similarity, skill-gap detection, SQLite, and FastAPI.
- **Tags:** `python`, `nlp`, `resume-screening`, `tf-idf`, `fastapi`, `scikit-learn`, `hr-tech`

## 6-Day Commit Plan
1. **Day 1:** Project setup, folder structure, `requirements.txt`, and `db/schema.sql`.
2. **Day 2:** Resume ingestion (`src/ingest.py`) for `.pdf`, `.docx`, and `.txt`.
3. **Day 3:** PII redaction and skill/experience extraction (`src/extract.py`).
4. **Day 4:** TF-IDF cosine similarity and gap-penalty ranking (`src/features.py`, `src/rank.py`).
5. **Day 5:** FastAPI service, Streamlit/Next.js UI, and Matplotlib ranking chart.
6. **Day 6:** Unit tests, evaluation script, `README.md`, and interview prep docs.
